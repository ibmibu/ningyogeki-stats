# 人形劇 Stats

スマメイトの人形劇シリーズを集計するアプリです。


## データのバックアップとオフライン利用

- 「全データを保存（JSON）」から、戦績データ・キャラクターコメント・手動キャラ報告・キャラクター名の別名設定をバックアップできます。
- 「バックアップJSONを読み込む」からバックアップを復元できます。
- 「オフラインモードにする」を有効にすると、保存済みデータを使い、Smashmateへのデータ取得リクエストを停止します。
- 現時点のバックアップは、GitHub上のアプリ本体とは別ファイルです。GitHubにJSONを保管してサイトから自動読込する仕組みは、次の作業で追加します。
