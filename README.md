# 人形劇 戦績表

Smashmateの「いぶさんの参加大会一覧」から「人形劇#数字」の大会を自動で拾い、各大会のトーナメント表から直接対戦結果を集計するNext.jsアプリです。

## データ取得の入口

`https://smashmate.net/user_add_tournament/?user=81727`

大会名に「人形劇#数字」が含まれる大会だけを対象にします。各大会のリンクから同じ大会IDのトーナメント表を取得します。

## ローカル起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## 注意

公開サイトからデータを取得するため、アクセス頻度を上げすぎないようにしています。Smashmate側の仕様変更や一時的なエラーがある場合は取得できない大会が発生する可能性があります。
