# 人形劇 Stats

Smashmate の「人形劇」シリーズを集計する Next.js アプリです。

## 今回の仕様

- 初回のみ全大会を取得
- 2回目以降は Smashmate の参加大会一覧を1回確認
- 保存済みの大会番号と比較し、まだ保存されていない大会だけ取得
- 新しい大会がなければトーナメントページ・bracketページ・選手ページを取得しない
- 取得済みの大会結果はブラウザの localStorage に保存
- 途中で取得に失敗した大会は未取得扱いになり、次回に再試行
- 「保存データをリセット」で全大会を取り直せる
- 既存の対戦表、選手選択、勝率ランキング、25大会ごとのシーズン表示、アカウント統合を維持

## 使用方法

このフォルダを GitHub のプロジェクトにそのまま上書きして push してください。
Vercel は GitHub の push を検知して自動デプロイできます。

初回アクセス時は全大会を取得するため時間がかかります。
2回目以降は保存データを表示しながら大会一覧だけを確認し、未取得大会がある場合だけ追加取得します。
